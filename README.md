# 춘식이 다마고치

첫 번째 실행 가능한 웹 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다.

GitHub Pages를 켜면 모바일에서도 웹앱처럼 사용할 수 있습니다.

## 현재 기능

- 먹이 / 운동 / 놀이 / 씻기 / 공부 / 잠
- 배고픔 / 행복 / 스트레스 / 피로 / 청결
- 건강 / 애정 / 지능 내부 능력치
- 행동 횟수 기반 진화
- 춘식이 도감
- 실제 시간 경과에 따른 성장 단계
- 5분 상자 발견 연출
- 음식/아이템 시스템
- 춘구마 청기백기형 반응 미니게임
- localStorage 자동 저장
- 모바일 반응형 UI

## 미니게임

`minigame.html`을 열면 **🍠 춘구마 밥주기**를 플레이할 수 있습니다.

- 춘구마가 물을 들면 `💧 물` 버튼
- 춘구마가 김치를 들면 `🥬 김치` 버튼
- 정답 1회마다 `0.1 kg`의 밥을 먹임
- 오답 또는 시간 초과가 실패 1회
- 실패 3회면 게임오버
- 최대 20라운드

> 춘식이 캐릭터와 관련 IP는 해당 권리자에게 있습니다. 공개·상업적 배포 전 필요한 권리와 라이선스를 확인하세요.
