# 춘식이 다마고치

첫 번째 실행 가능한 웹 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다.

GitHub Pages를 켜면 모바일에서도 웹앱처럼 사용할 수 있습니다.

## v0.1 기능

- 먹이 / 운동 / 놀이 / 씻기 / 공부 / 잠
- 배고픔 / 행복 / 스트레스 / 피로 / 청결
- 건강 / 애정 / 지능 내부 능력치
- 행동 횟수 기반 진화
- 7종 초기 진화형
- 춘식이 도감
- 실제 시간 경과에 따른 상태 변화
- localStorage 자동 저장
- 모바일 반응형 UI
